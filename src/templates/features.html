功能一览

从显示、提醒到编辑、自定义，ClassFabric 沿用 ClassIsland 成熟的功能体系，并加入了社区新增的改进。带 新 标记的是 ClassFabric 自己新增的内容；带 同步自上游 标记的来自 ClassIsland，不算 ClassFabric 原创。

课表显示与提醒课表编辑与管理自定义自动化天气其他
01

课表显示与提醒

主界面上的课表条会显示当天课程与正在进行的课，在重要时间点提醒你，又不会挡住教学内容。

  • 当天课表与当前课程当前课程展开显示名称与时间，进度条随课程推进。
  • 上下课提醒可搭配音效、强调特效、语音与置顶效果，并支持自定义强调提醒。
  • 隐藏条件与鼠标穿透自选课表隐藏条件，支持临时隐藏与鼠标穿透，不影响授课。
  • 竖直课表条 新Beta贴靠屏幕左右边缘，等高格显示全天课程，已结束的课程自动变暗，并带有全天进度细轨。
  • 竖条提醒 新Beta下课时轮播提醒，上课前 60 秒自动切换为下一节课的预览。
02

课表编辑与管理

可视化的档案编辑器：课表、时间表、课程、科目、调课，都在一个窗口里完成。

  • 简洁直观的编辑工具点一个空格、选一个科目，选完自动跳到下一节。
  • 导入与导出从 Excel 表格、CSES 或其他软件导入课表，也能导出到 Excel。
  • 多周轮换与快速录入支持多周轮换，时间表可在时间轴上拖拽快速录入。
  • 临时换课与预定课表单日或跨天临时换课；提前预定要临时启用的课表。
  • 科目主题色、图标与地点 新为每个科目设置图标、主题色、简称、任课老师与地点，已有数据自动迁移。
  • 窄屏与触屏适配 新日程课表编辑器适配窄屏幕，并修复了触屏不可用的问题。
03

自定义

组件决定屏幕上显示什么，主题决定它长什么样，插件决定它还能做什么。

  • 组件日期、时钟、天气简报、倒计时、文本等；支持多行显示、组件轮播与滚动。
  • 主题系统通过主题高度定制主界面外观，并自动获取与系统搭配的主题色。
  • 插件与插件市场在线安装与更新，支持镜像源与自定义插件源。
  • ClassIsland v2 插件兼容层 新让针对 ClassIsland v2 的插件继续可用。
  • 插件加载诊断 新加载失败时给出可读的诊断信息，并支持一键复制。
  • 三语界面 新简体中文、繁體中文、English，在设置中切换，重启后生效。
  • 图标选择器与提醒动作图标 同步自上游为图标选择提供统一的选择器，提醒动作也能使用自定义图标。
04

自动化

让 ClassFabric 在特定事件发生或特定时间点，自动做一些事，提高教学效率。

  • 触发器、规则集、行动事件触发时，在满足规则集的情况下执行行动。
  • 自动恢复规则集不再满足时，可自动恢复先前的行动。
  • 常见行动显示提醒、打开应用、文件或网页等。
05

天气

把天气放进课表条，出门前、课间都能一眼看到。

  • 实时天气与预报当前天气、降水提示、6 小时 / 3 天预报，支持根据定位获取。
  • 极端天气预警有预警时直接提醒。
  • 多天气源与自动回退 新支持多个天气源，某个源请求失败时自动回退到其他源。
06

其他

那些不起眼、但每天都在用的细节。

  • 时间同步与铃声对齐自动同步软件时间，也能手动对齐铃声。
  • 密码保护用密码等认证方式保护应用设置与课表配置。
  • 过渡动画课程切换与提醒弹出都带有过渡效果。
  • 自动更新与更新通道 新以 GitHub Releases 为更新源，可选稳定版或预览版通道。
  • 新版主界面 同步自上游实验性导航框架、竖直课程控件与日程课表，仅在调试菜单中提供。
