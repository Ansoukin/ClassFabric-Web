首页/与 ClassIsland 的关系

站在 ClassIsland
的肩膀上。

ClassFabric 是 ClassIsland 的社区衍生版本（二创版）。我们的出发点很朴素：在一个已经很好用的课表工具上，加一些自己的东西。

我们和它的关系

ClassIsland 是由其团队与众多贡献者共同维护的开源课表工具。ClassFabric 基于它继续开发——具体来说，是基于上游的 develop/v2/misha-alpha 分支，并保留了 ClassIsland v2 的插件兼容层。

就像社区里常见的“增强版”项目那样，我们不另起炉灶，而是在上游之上叠加自己的改动，并尽量与上游保持同步。ClassFabric 不是官方版本，也不代表上游团队。

继承

来自 ClassIsland

  • 课表灵动岛、课表显示与提醒
  • 档案编辑器、导入与导出
  • 组件与主题系统
  • 插件机制与插件市场
  • 自动化与天气
  • 基础用法与使用文档
新增

ClassFabric 的改动

  • 简体中文 / 繁體中文 / English 三语界面
  • 科目主题色、图标与地点
  • 多天气源与自动回退
  • GitHub Releases 更新源，稳定 / 预览通道
  • 插件加载的可读诊断
  • 竖直课表条与竖条提醒（Beta）
取舍

我们暂时不做的

  • 仅支持 Windows，不提供 Linux / macOS / Android 安装包
  • 没有自己的群聊，交流在 GitHub 上进行
  • 下载入口独立：ClassIsland 官网提供的是 ClassIsland

“新增”一栏只列 ClassFabric 自己的提交（按发行说明里的提交链接核对）；同步自上游的内容在下面单独列出。每个版本的具体改动见更新日志。

同步自上游

这些不是
我们写的。

ClassFabric 会不时把上游的改动同步进来。同步来的内容原作者是上游的开发者，我们不把它算作自己的功劳，在更新日志里也单独归类。

  • 2.1.1.1 上游提交日程查询 API、日程课表编辑器、图标表达式、图标选择器、提醒动作自定义图标（作者 @HelloWRC，发行说明附有原提交链接）。
  • 2.1.1.3 上游同步新版主界面（导航框架、竖直课程控件、日程课表），实验性，仅在调试菜单中提供。

归属依据是 ClassFabric 的 GitHub 发行说明；若发现遗漏或写错，欢迎到 Issues 指出。

常见问题

你可能想问

ClassFabric 的文档在哪里？{{ ico('chevron_down', 20) }}

目前沿用 ClassIsland 的使用文档（docs.classisland.tech），基础用法一致。ClassFabric 独有的功能，请看本站的功能与更新日志。

为什么在 ClassIsland 官网下不到 ClassFabric？{{ ico('chevron_down', 20) }}

那里的下载入口提供的是 ClassIsland。ClassFabric 请使用本站的下载页或 GitHub Releases。

ClassIsland 的插件能用吗？{{ ico('chevron_down', 20) }}

ClassFabric 保留了 ClassIsland v2 的插件兼容层，目标是让针对 v2 的插件继续可用。个别插件如果出现问题，欢迎到 Issues 反馈，并附上插件加载诊断信息。

可以加入 ClassFabric 的群聊吗？{{ ico('chevron_down', 20) }}

暂时没有。ClassIsland 的 QQ 频道与群聊属于上游，并不是 ClassFabric 的。ClassFabric 目前通过 GitHub 的 Issues 与 Discussions 交流。

支持 Linux、macOS 或 Android 吗？{{ ico('chevron_down', 20) }}

暂不支持。仓库里保留着相关代码，但我们没有测试环境，也没有精力维护，所以不提供安装包，也不保证可用。如果你愿意帮忙测试或维护，请在社区页看看怎么参与。

更新日志里，哪些是 ClassFabric 自己做的？{{ ico('chevron_down', 20) }}

更新日志按提交归属分组：「ClassFabric 新增与改进」是我们自己的提交，「同步自上游」是从 ClassIsland 同步来的，带「非 ClassFabric 原创」标记。

它是开源的吗？{{ ico('chevron_down', 20) }}

是的，以 GPL-3.0 协议开源，源码在 GitHub。ClassIsland 受 DuguSand/class_form 启发而开发，ClassFabric 同样感谢它们。
